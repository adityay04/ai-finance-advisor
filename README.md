# SME AI Advisor 📊

An AI-powered financial advisor for small business owners. Upload your bank CSV, ask a question, and get instant, actionable insights powered by Groq's Compound AI.

## Features

- **Upload CSV** – Auto-detects amount and category columns.
- **AI Reasoning** – Uses Groq's `compound` model for intelligent financial analysis.
- **Visual Dashboard** – Bar charts and pie charts for spending breakdown.
- **Actionable Advice** – Get specific recommendations based on your spending patterns.

## Tech Stack

- **Frontend**: Streamlit
- **AI**: Groq API (`groq/compound` model)
- **Data**: Pandas
- **Charts**: Plotly
